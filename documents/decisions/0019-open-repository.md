# 19. Open repository

Date: 30/07/2026 15:01

## Status

ACCEPTED

## Context

The repository has been internal only since it was created. This causes some issues with access (people don't seem to be able to get in) and goes against the ONS GitHub Usage Policy which requires a PIRR.md (a private/internal repo reasoning record file). Sam I reached out to Charles B to see if there was a reason to keep it internal and there wasn't. 

## Decision

To open the repository.

## Consequences

This should solve access problems. Sam I and other people working on the repository might need to be more careful with their commentary going forward. People external to the ONS might catch wind of it and start asking if we need help with our catalogue. Their enquiries will be redirected to Charles unless they are being genuinely helpful.
